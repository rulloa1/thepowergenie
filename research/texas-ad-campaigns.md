### Ad Set Settings

#### Targeting (Same for All Ad Sets, Adjust Geo)

| Setting | Value |
|---------|-------|
| **Objective** | Leads (Lead Gen Form or Conversions) |
| **Location** | 25-mile radius around city center |
| **Age** | 30–60 |
| **Gender** | All |
| **Demographics** | Homeowners |
| **Income** | Top 50% ($75K+ household) |
| **Interests** | Home improvement, Energy efficiency, Tesla, Sustainability, Solar energy, Home Depot, Lowe's |
| **Behaviors** | Likely to move (exclude), Engaged shoppers |
| **Placements** | Automatic (or Facebook Feed + Instagram Feed for testing) |
| **Budget** | $20–50/day per ad set to start |
| **Bid Strategy** | Lowest cost (then switch to cost cap once you have baseline CPL) |

**Form Fields:**

5. "Do you own your home?" (Yes / No / Renting but interested)

## Tracking & Attribution

Add UTM parameters to all ad links:

**Facebook:**
```
?utm_source=facebook&utm_medium=paid&utm_campaign=texas-solar&utm_content=[ad-name]
```

**Google:**
```
?utm_source=google&utm_medium=cpc&utm_campaign=texas-solar&utm_content=[ad-group]
```

This lets you track which ads drive leads in your CRM.
